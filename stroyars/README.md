# Строярс — дизайн сайта (ПК-версия)

Дизайн сайта компании «Строярс»: дизайн интерьера и ремонт квартир и домов под ключ в Краснодаре.
Только десктоп: макет рассчитан на экраны от 1280 до 1920 px, основная ширина — 1440 px.

Запуск: двойной щелчок по `index.html`. Всё локально — шрифты в `fonts/`, интернет не нужен.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: первый экран с тремя кнопками, «кому не подойдём», калькулятор, портфолио, этапы, видеоотзывы, о компании, статьи, контакты |
| `article.html` | Шаблон SEO-статьи: «Штукатурка стен по маякам своими руками» с кнопкой «Заказать у нас оштукатуривание стен» |
| `project.html` | Шаблон страницы объекта из портфолио: факты план/факт, до/после, галерея, видеоотзыв |

## Идея

Первый экран повторяет формулу из брифа: три кнопки, после которых человеку больше ничего не нужно.

1. **Видео** «Строярс за 2 минуты».
2. **Расчёт**: поле с квадратурой и выбор класса отделки (Базовый / Оптимальный / Премиальный). Цена считается сразу.
3. **Портфолио**.

Всё остальное ниже нужно для SEO, прогрева и отсева неподходящих клиентов. Блок «Кому мы не подойдём» прямо отсеивает тех, кто ищет самую низкую цену.

## Стиль

- **Премиальный минимализм + стекло.** Карточки из матового стекла (`backdrop-filter`) лежат поверх фотографий объектов.
- **Цвет.** Мокрый графит `#0F1110`, известковая штукатурка `#ECE7DE`, камень `#A19D94`, дуб `#B08A62`.
- **Фирменный знак — луч лазерного уровня** `#62FF9A`. Это единственный цветной элемент. Он появляется там, где речь о точности и о вашем участии: горизонт на первом экране, ползунок калькулятора, этапы, на которых нужны вы, прогресс чтения статьи и линия «до/после».
- **Шрифты** (лежат локально в `fonts/`): Geologica для заголовков, Golos Text для текста, JetBrains Mono для цифр и подписей.

## Что заменить перед запуском

- `img/*.jpg` — **временные иллюстрации-заглушки** (сгенерированы). Их нужно заменить фотографиями объектов с строярс.рф. Пропорции и кадрирование задаются в CSS через `object-fit: cover`.
- Логотип: сейчас стоит текстовый знак. Нужен векторный логотип заказчика, после чего стоит сверить с ним палитру.
- Цифры: ставки калькулятора (`app.js` → `RATE`, `DESIGN`, `PACE`), число объектов, лет работы, контакты, имя основателя и ИНН. Всё это **примеры**, их нужно подтвердить у заказчика.
- Видео: модальное окно пока показывает заглушку.
